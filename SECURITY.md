# Security and acceptable use

This repository is for systems the operator owns or is explicitly authorized to test.

The project must not be extended to:

- evade bot detection or browser fingerprinting controls;
- solve or bypass CAPTCHA, OTP, Cloudflare, or access-control challenges;
- create bulk orders against third-party production stores;
- manipulate referral or affiliate attribution;
- evade rate limits or account restrictions;
- use real customer identities, addresses, or payment data.

Use staging endpoints, synthetic accounts, test payment methods, explicit allowlists, and bounded traffic. Report security issues privately to the repository owner.
